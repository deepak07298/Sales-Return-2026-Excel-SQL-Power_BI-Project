Sales Return 2026 – Excel, SQL & Power BI End-to-End Project

Project Overview

This project is an end-to-end Sales Return Analysis project developed using Microsoft Excel, MySQL, and Power BI.

The objective of this project is to analyze sales return transactions, identify material-wise and party-wise patterns, evaluate weight and amount trends, and present meaningful business insights through an interactive Power BI dashboard.

Tools & Technologies

- Microsoft Excel – Data preparation and initial analysis
- MySQL – Data storage, querying, and business analysis
- Power BI – Data visualization and interactive dashboard
- SQL – Business queries, aggregations, CTEs, and Window Functions

Power BI Dashboard

The final analysis was transformed into an interactive Power BI dashboard consisting of two pages.

Page 1 – Overall Summary

The first page provides a high-level overview of the sales return data using:

- KPI Cards
- Material-wise analysis
- Amount analysis
- Daily trend analysis
- Material contribution analysis
- Party-wise amount analysis

Page 2 – Weight & Rate Analysis

The second page provides detailed analysis of:

- Weight by Party Address
- Material-wise Total Weight
- Daily Weight Trend
- Average Rate by Material

Interactive Filters

The dashboard includes three interactive slicers:

- Date
- Material
- Party Address

These filters allow users to dynamically explore the dashboard according to their requirements.
